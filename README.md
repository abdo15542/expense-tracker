# تتبّع المصروفات — تطبيق Android

تطبيق Android حقيقي (Capacitor) لتتبّع المصروفات والدخل، بالعربية وباتجاه RTL.
البيانات تُحفظ محلياً على الهاتف نفسه (localStorage داخل التطبيق) وتبقى بعد إغلاقه.

## الميزات
- إضافة / تعديل / حذف مصروفات ودخل (مبلغ، تصنيف جاهز أو مخصص، تاريخ، ملاحظة)
- ملخص شهري: الدخل، المصروفات، الصافي
- ميزانية شهرية مع شريط تقدّم وتنبيه عند التجاوز، واختيار العملة (افتراضي: دينار ليبي)
- توزيع المصروفات حسب التصنيف، ورسم مصروفات آخر ٦ شهور
- بحث وتصفية، والتنقّل بين الشهور
- تصدير CSV ونسخة احتياطية JSON، واستيراد النسخة الاحتياطية

## استخراج الـ APK من GitHub
1. ادفع (push) المشروع إلى GitHub — سيعمل Workflow اسمه **Build APK** تلقائياً عند كل دفع إلى فرع `main`، ويمكن تشغيله يدوياً من تبويب **Actions ← Build APK ← Run workflow**.
2. بعد نجاح التشغيل، افتح صفحة التشغيل ونزّل Artifact باسم **expense-tracker-apk**.
3. بداخله ملف `app-debug.apk` — انقله إلى هاتفك وثبّته (قد تحتاج تفعيل «التثبيت من مصادر غير معروفة»).

> ملاحظة: هذا APK بنسخة Debug — قابل للتثبيت والاستخدام الفعلي.
> للنشر على Google Play لاحقاً نحتاج نسخة Release موقّعة بمفتاح توقيع (keystore) خاص بك.

## البناء محلياً (اختياري)
```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
يتطلب محلياً: Node 20، و JDK 17، و Android SDK.
